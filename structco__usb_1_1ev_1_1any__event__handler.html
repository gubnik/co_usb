Detailed Description

Owning type-erased wrapper for EventHandler.

This type is used to uniformly store objects of any type that conform to co_usb::ev::detail::EventHandler concept. It allocates the space for the buffer using a given pointer to a memory resource and will preserve this pointer inside of itself.
