Detailed Description

template<detail::TransferSequence TSeq, endpoint_direction EpDirection>
struct co_usb::transfer::isochronous_complete_io< TSeq, EpDirection >

Prefills the transfer sequence as isochronous transfers and provides complete I/O operations.

Note
Requires all transfers in a transfer sequence to be allocated with the number of iso packets valid for a given iso_packets value.
